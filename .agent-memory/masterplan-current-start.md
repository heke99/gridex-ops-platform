Befintlig seriell leveransägare gör normal merge; rapportera ökning först efter autentiserad PR-state, ordered parents/tree och färsk ledger.

Pensionerade agenter och gamla pausade automationer återupptas inte; #310 förblir PAUSED. Verkliga utskick, persondatagallringar, secrets och produktionsaktiveringar kräver faktiskt behörigt underlag. Separata publiceringsbeslut och åtkomstgränser bevaras; tystnad är inget godkännande.
