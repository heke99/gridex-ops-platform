# Structure

- `app/`: Next.js routes, pages and API handlers.
- `lib/`: domain/runtime services; Ediel is under `lib/ediel`.
- `supabase/migrations/`: immutable history plus forward migrations.
- `scripts/`: mechanical regressions, migration governance and release checks.
- `__tests__/`: Vitest contracts.
- `docs/` and `.agent-memory/`: operating and domain context.
