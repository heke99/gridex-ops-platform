# API 2026-07-24.2 – canonical market-price completion

## Added

- `POST /api/v1/website/market-price/current`.
- Scope `website_market_prices.read`.
- Direct price fields in `market_reference` in both SEK/kWh and öre/kWh.
- `requested_days`, `included_days`, `source_as_of`, `generated_at`, `stale_after` and `effective_stale_at`.
- Machine-readable market-price errors.
- Hourly spot-price import for the previous, current and—after publication time—next Stockholm calendar day.
- Idempotent preview publication that does not refresh unchanged evidence.

## Clarified

- `public-contracts` is a product and selection feed and does not contain a current dynamic spot price.
- `market-price/current` is the current wholesale market interval, not the complete customer price.
- `quote` is the canonical customer calculation including pricing components, fees, discounts and VAT.
- `resolution_id` is authoritative for SE1–SE4.
- Preview data is never final settlement evidence.

## Fixed

- A one-day preview can no longer silently look like a complete 30-day window.
- Tenant `allow_indicative_latest=false` is enforced when choosing a preview.
- Provider priority and tenant freshness are applied to preview selection.
- `market_reference` no longer exposes provenance without the actual numeric market price.
- `source_as_of` is derived from provider evidence and is separate from `generated_at`.
- Website API documentation, route registry, OpenAPI and runtime are versioned together.

This release is additive within V1. Existing fields are not removed.
