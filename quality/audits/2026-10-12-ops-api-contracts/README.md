The audit uses actual OPS handlers, their callees, and the connected PostgreSQL catalog as authority. Tests verify local changes and are not evidence that the deployed APIs or database are correct. Gridex Web is outside scope. No business RPC, live customer mutation, provider request, email, native capture, job replay or deployment was performed. Twelve explicitly authorized OPS forward DDL migrations have been applied and checked against actual metadata; see `atomic-native-apply-receipt.json`, `global-deny-grid-owner-native-apply-receipt.json` and `staff-governance-native-apply-receipt.json`.
