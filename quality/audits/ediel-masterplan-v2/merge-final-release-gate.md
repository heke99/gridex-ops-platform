# Bound native release verification

Status: implemented and locally verified; actual complete native acceptance is
pending. No main merge or reference/type regeneration is claimed here.

The ordinary entry now records its invocation start before the owned lifecycle.
A successful process exit is insufficient. The final verifier requires fresh
lifecycle, schema and candidate artifacts; complete original/native-forward
receipts; original five final SQL gates; production parity qualification;
matching source-witness receipts; disposed owned resources; exact positive schema
decisions; genuine candidate bytes equal to committed types and the manifest;
and the exact current migration tail. Unsupported differences remain failures.

The schema decision engine currently maps 1024 exact differences: 31 added views,
five changed views, 128 changed policies, 59 removed policies, five changed
indexes, two intake columns, 51 removed indexes, 14 non-type column differences
five positive CHECK changes, the qualified intent customer/company FK, and723 exact physical-ordinal-only differences. These are explicit source decisions bound to
actual witness receipts, not approval inferred from the larger inventory.
The two repaired removals are specifically ediel_send_locks tenant INSERT and
UPDATE policies; they require exact forward six plus the full current forward
receipt. Unknown, missing, duplicate or changed reviewed mappings fail. The 24
policies removed by forward ten are added-policy identities outside these
mandatory mappings; no mapping-disappearance exception was introduced.

The old normalized dump gate is independently preserved. Before disposal the
owned native target runs socket-only PG17 pg_dump twice with the original
schema-only/no-owner/no-tablespaces/public options. The unchanged pinned
production normalizer processes the bytes. Both captures must match, sources
and database/ledger state must remain unchanged, and the final verifier requires
exact equality with the normalized pinned schema.sql. Raw dumps remain in memory;
only hashes, byte/line counts and closed flags are retained. A dump mismatch is
still a release blocker. Accepted introspection decisions do not substitute for
this check and do not certify default privileges or other omitted structures.
