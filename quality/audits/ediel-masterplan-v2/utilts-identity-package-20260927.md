## Bounded code milestone: supplied E66 LOC+172 field 209 and GS1 length

U annex C UG-123-11/12 requires nonblank LOC+172/C517/3225, a GS1 control digit where applicable, and agency 9 or 89. The existing E66 facade produced generic 515/512 for an empty supplied identity and let wrong agency/control digits pass to the later E19 functional result. A RED test reproduced this. The central per-IDE guide now reports 209/ERC 41 or 42 before function and leaves a valid sibling eligible. The real `processInboundUtiltsMessage` test verifies tenant-bound persistence input, negative APERAK with 209, no rejected-IDE meter/billing/completion and one valid sibling's meter/billing writes. Source-valid positive 172 retains its prior functional outcome.

GS1 Sweden's electrical-installation GSRN guide states that a GSRN has exactly 18 digits including the control digit (`https://gs1.se/guider/kom-igang-guider/identifiera-och-marka-elanlaggningar/`); its modulo-10 guide is `https://gs1.se/guider/sa-beraknas-kontrollsiffran/`. Previously a 17-digit agency-9 value skipped arithmetic in both LOC+172 and LOC+175. RED tests showed this; a shared 18-digit/modulo-10 predicate now yields 209 or 533/ERC 42. Agency 89 is excluded from GS1 arithmetic. This is validation of supplied values, **not** a positive LOC+175 sink or a historical uniqueness claim.
