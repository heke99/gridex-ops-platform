## Öppet schema-/semantikgränssnitt för masterplanagenten

`domain_events.event_version` finns i tabellen men `portal_customer_events_page_v1` projicerar inte den kolumnen. `publicPortalEvent` ser därmed `undefined` och svarar alltid med fallback `1`, även för lagrad version större än 1. Detta är ett faktiskt semantikfel i read-modellen; 29.5 beskriver nuvarande svar och guiden anger begränsningen. För en korrekt version krävs en samordnad framåtmigration med en ny service-role-grantad `portal_customer_events_page_v2` (v1:s tabellreturtyp kan inte ändras via enkel `CREATE OR REPLACE`). Behåll exakt tenant-/kundfilter, ordning, cursor och limit; projicera `domain_events.event_version` och ge kundhändelser en uttrycklig `1` eller deras verkliga version. API-koden byter till v2 när native test med version >1, båda källor, två kunder, samma tidsstämpel och cursor-replay har passerat; därefter kan en ny release lova korrekt version. Masterplanägaren behöver också avgöra vilka eventtyper som alls är kundsynliga innan flödet kvalificerar P4. Ingen konkurrerande SQL skapas här.

Externt supportärende/meddelande/bilageresurs finns ännu inte i runtime eller route-registret; P6:s kundinloggning → ärende → OPS-svar → återläsning kan därför inte kvalificeras av dessa läsningar. **T48** får ytterligare avgränsad PARTIAL evidens för två operationer; **T26/T53/P4/P6** och varje helt T/U-ID kvarstår. Lokal kontroll och exakt CI anges i #422 efter publicering.

## Sanningsenlig versionsfält-korrigering, kandidat 2026-09-29.6

Efter att 29.5 publicerats på #422 skrevs två **RED 2/2** mot faktiskt API-DTO och GET-route: det saknade `event_version` från sid-RPC:n projicerades felaktigt som `1`. API-projektionen returnerar nu JSON null när läsmodellen saknar ett positivt heltalsvärde, men bevarar en faktiskt levererad version, exempelvis 3. `CustomerEvent.event_version` är `integer | null` i den nya OpenAPI-releasen. Klienten och guiden visar null. Detta rättar felaktig presentation utan att hävda att den lagrade versionen finns i v1-RPC:n; masterplanens v2-gränssnitt och native prov ovan återstår.
